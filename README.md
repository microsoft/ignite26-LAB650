# [Microsoft Ignite 2026](https://ignite.microsoft.com)

## 🔥LAB650: Build a Knowledge-Powered Workspace with Copilot in SharePoint
### Session description

Learn how to transform content into organizational knowledge and put AI to work across your team. You'll use Copilot in SharePoint to organize information, enrich content with metadata, create pages and reports, build reusable skills, and automate common processes. Along the way, you'll see how better-organized knowledge helps strengthen Copilot experiences across Microsoft 365. Leave with practical techniques you can apply immediately to build a modern, AI-powered knowledge workspace.

### 🚀 Getting started

#### In a guided session

If you're following along during a live session:

1. Open **Edge** on your lab desktop and follow the **Lab setup** steps in [`instructions/`](instructions/README.md) to sign in with your lab user name and password. Use that account for the whole lab.
2. Choose your path: **Track A then Track C** to build an account knowledge base and put it to work, or **Track B** to explore a shared field-service knowledge base. The tracks are independent. In Track B, follow the presenter for the MC-led tasks.
3. Continue in [`instructions/`](instructions/README.md) for step-by-step guidance on each task.
